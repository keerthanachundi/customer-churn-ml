IBM Telecom Customer Churn

Churn

customerID

tenure

Validation Rules:

1. Dataset must not be empty.
2. Churn column must exist.
3. MonthlyCharges must be numeric.
4. tenure must be numeric.
5. Required columns must exist.
6. Duplicate customer IDs should not exist.
